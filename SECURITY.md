# Security Policy

## Reporting Vulnerabilities

If you discover a security vulnerability in this repository or any public-facing Therapals endpoint, please email **security@therapals.app**. We follow a coordinated disclosure policy with a 90-day window for investigation and remediation.

- **Scope:** This policy covers only this repository and public endpoints. Internal app code is private and not in scope.
- **No PHI:** Never submit real patient data or PHI in reports or examples.

## Disclosure Timeline
- Initial response: within 5 business days
- Remediation: up to 90 days

Thank you for helping keep Therapals safe!
