## What is Therapals?
Therapals is a secure SaaS platform for therapists, clinics, and integrators. It streamlines session notes, compliance, and data exchange—without storing PHI in this public repo.

- **Live App:** [https://therapypals.vercel.app](https://therapypals.vercel.app)
- **Docs:** [./docs](./docs)
- **Schemas:** [./schemas](./schemas)
- **Security Policy:** [./SECURITY.md](./SECURITY.md)
- **Roadmap:** [./ROADMAP.md](./ROADMAP.md)
- **Support:** support@therapals.app

> - Core application code lives in private repositories ([therapals/therapypals](https://github.com/therapals/therapypals), [therapals/therapypals-api](https://github.com/therapals/therapypals-api)) If you would like to contribute email caleb1mb24@gmail.com
