# Contributing to Therapals Open

Thank you for your interest! This repo only accepts contributions for documentation, schemas, examples, and SDKs. **No production code or PHI.**

- **Scope:**
  - Docs, schemas, examples, SDKs only
  - No production issues—use the in-app support form for app bugs
- **Style Guide:**
  - Use markdownlint (see config)
  - No PHI; use only fake data
  - Keep examples simple and safe
- **How to Contribute:**
  - Fork, edit, and submit a PR
  - All PRs are reviewed for safety and clarity
