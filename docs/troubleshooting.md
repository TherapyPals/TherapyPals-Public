# Troubleshooting Docs & Examples

This section covers issues with public docs, schemas, and examples only. For app support, use the in-app support form.

## Common Issues
- **Schema validation errors:** Ensure you use only fake data and match the schema format.
- **API mock failures:** Check endpoint URLs and payload shape.
- **Markdown linting:** See [.markdownlint.json](../.markdownlint.json) for style rules.
