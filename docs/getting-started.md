# Getting Started with Therapals

Therapals is a secure SaaS for therapists and clinics. This repo provides public docs, schemas, and examples—no PHI or production code.

## Value Proposition
- Streamline session notes and compliance
- Integrate with EHRs and third-party tools
- Developer-friendly schemas and mock endpoints

## High-Level Architecture
