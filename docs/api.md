# API Overview

## Public API Status
No production API is available yet. This repo provides mock endpoints and schemas for testing and integration.

- **Mock Host:** https://api.mock.therapals.app
- **Postman Collection:** [therapals-public-mock.postman_collection.json](./postman/therapals-public-mock.postman_collection.json)

## Example Endpoints
- `POST /notes/soap` — Accepts SOAP note JSON (fake data only)
- `POST /notes/dap` — Accepts DAP note JSON (fake data only)
- `POST /notes/birp` — Accepts BIRP note JSON (fake data only)

See [schemas](../schemas) and [examples](../examples) for payload formats.
